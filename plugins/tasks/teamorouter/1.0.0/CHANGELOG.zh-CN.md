# Changelog

## [1.0.0]

### Added

- 用 TeamoRouter API Key 把任务插件渠道接到 TeamoRouter，默认地址为 `https://api.teamorouter.com`。
- 通过 TeamoRouter 提供对话补全、Responses、Claude Messages、Gemini 内容生成以及图片生成和编辑，所有文本接口都支持流式输出。
- 用「获取模型」加载 TeamoRouter 密钥可用的模型。
- 在渠道余额里查看每个密钥的可用余额，单位为美元。
