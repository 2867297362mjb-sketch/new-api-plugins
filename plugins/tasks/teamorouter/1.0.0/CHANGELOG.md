# Changelog

## [1.0.0]

### Added

- Connect a Task Plugin channel to TeamoRouter with a TeamoRouter API key, at `https://api.teamorouter.com` by default.
- Serve chat completions, responses, Claude messages, Gemini content generation and image generation and editing through TeamoRouter, with streaming on every text endpoint.
- Load the models your TeamoRouter key can use with "Fetch Models".
- See the available balance of each key, in USD, in the channel balance.
